# SoH3D parity map — the CLOSED-CASES registry

The authoritative list of what is **CONFIRMED AT PARITY** with the OoT3D/MM3D oracle. This is the
third orientation map, alongside `docs/codemap.md` (what CODE exists) and `docs/re-frontier.md`
(RE progress / hacks). Consult all three at the START of a task:
**parity-map = skip closed cases · codemap = find the code · re-frontier = next RE step.**

## THE RULE (this map's whole purpose)

**A `CLOSED-parity` item is DONE and is NOT to be re-examined by sweeps, loop iterations, or
autonomous parity passes.** It reopens ONLY on:
1. an explicit **USER request** to reopen the case, or
2. a **confirmed regression** (a matched-frame oracle A/B or a user playtest showing it broke) —
   in which case flip its Status to `REOPENED`, add the regression evidence, and it becomes live
   work again.

This is the mechanism that enforces the global "mark verified, don't revisit" rule
(`<claude-config>` memory `mark-verified-dont-revisit`, `soh3d-parity-meaning`): once a thing is proven
at parity against the oracle, spending further loop budget re-measuring it is waste. Do not
micro-tune a CLOSED lighting/terrain item — several are explicitly **OFF-LIMITS to tuning** by
direct user instruction (`soh3d-stop-microtuning-lighting`, `soh3d-lighting-port`); reopening one
to "improve" it is a rule violation, not initiative.

**How this map relates to the generated checklists:** the Link/MM state rows below are a
CONSOLIDATED, human-authored snapshot. The live, per-run generated detail lives in
`docs/link_parity_checklist.md` (regenerated by `tools/link_sweep.py sweep`) and
`docs/mm_parity_checklist.md` (hand-maintained seed). This map cites their summary + resolving
commits so a session sees "closed, don't re-sweep" without re-running the sweep; the checklists
remain the source of truth for the fine-grained metric of each state. A generator that aggregates
the checklists' MATCH rows into this map's format automatically is a reasonable **follow-up** (see
bottom) — for now this map is hand-authored and authoritative.

Status vocabulary: **CLOSED-parity** (proven at parity, do not revisit) · **OPEN** (not yet at
parity — live work) · **REOPENED** (was closed, regressed — live work again).
