# Prior art — Ocarina of Time 3D (USA `CTR-P-AQEE`, decompressed `.code` MD5 `20c7ec6288ba0af4feb6db646c6cc6d5`, base `0x00100000`) and Majora's Mask 3D (USA `CTR-P-AJRE` 1.0, base `0x00100000`)
